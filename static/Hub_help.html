⚙ Hub — 3D Guide

Enabling the Hub

Checkbox in the Hub section header. When checked, a cylindrical boss is built on top of the toothed section and included in the 3D preview and all exports (STL, STEP). When unchecked, no hub geometry is generated — the pulley is a plain toothed disk with a through-bore.

The Hub section is only visible in 3D Mode.

Hub OD (mm)

Outer diameter of the hub boss. Can be narrower or wider than the pulley OD — no restriction. A narrower hub tucks the boss inside the tooth rim; a wider hub creates a flange overhanging the teeth. For captured nut retention, the hub may grow a rounded lobe in the screw direction if the entered OD is too small to provide adequate wall thickness.

When the Spokes option is active, Hub OD is controlled by the pulley's 2D spokes setting.

Hub Height (mm)

Axial height of the hub boss above the toothed section. The bore runs through the full combined height (Belt Height + Hub Height). For captured nut retention, this value is automatically raised if the nut pocket requires more depth than entered — the 3D model uses the adjusted height without changing the input field.

Shaft Retention

  • None — No set screw or shaft feature is added. The bore is a plain through-hole. Suitable for a light-duty fit or when you will add your own retention (e.g. shaft collar, adhesive).
  • Set Screw (threaded) — Radial screw hole(s) drilled from the outside of the hub in to the bore (one side only). The screw cuts its own thread in the plastic, so the hole is smaller than the screw: how much smaller is set app-wide in Threaded screw holes (see below). 1 screw = single perpendicular hole. 2 screws = holes placed 90° apart.
  • Set Screw (captured nut) — A standard hex nut is dropped into a pocket opening from the top face of the hub. The set screw passes through the hub wall into the nut and contacts the shaft. Stronger than threading into plastic. The screw's hole is a plain clearance hole (ISO 273) — the nut carries the thread, so the hole is never threaded.
    The nut pocket is sized from the screw size (DIN 934 metric nuts; standard machine-screw nuts for inch sizes).
    ⓘ 3D Print Guide — captured nut assembly, pocket shape, print settings
  • Set Screw (heat-set insert) — A threaded brass insert is pressed into the hole with a hot soldering iron, and the set screw threads into the insert. Enter Insert hole ⌀ from your insert's datasheet (it starts at about 1.35 × the screw size). The strongest choice for a screw you will tighten hard or often.
A D-flat, keyway or spline is the Bore Shape, in the pulley's Size card (2D), not a Retention choice: the bore is cut the same with or without a hub. With a flat or keyway, a set screw here is a single screw, aimed at the flat or into the key slot, and the captured nut sits against that face. A spline drives the pulley itself and a retaining ring holds it on (Bore Shape), so Retention is None while the bore is a spline.

Set Screw Size and Number of Screws

Set Screw Size: metric M2–M10 or inch #2-56 to 1/4-20. The hole cut depends on how the screw holds — the line under the hub settings says exactly what will be cut:

  • Threaded — the self-tapping hole from Threaded screw holes (an M5 at the default 50% gets a 4.57 mm hole).
  • Captured nut — a clearance hole (M5: 5.5 mm) and that size's nut pocket.
  • Heat-set insert — the insert hole you enter.
  • Custom… — any other screw: enter the hole diameter yourself (with a captured nut, the pocket fits the metric nut nearest that hole).

Number of Screws: 1, or 2 — threaded screws and inserts 90° apart, captured nuts 180° apart. Hovering Number of Screws shows the picture for the retention method you have selected.

Threaded screw holes

The Threaded screw holes button in the top bar (3D mode) sets how tight a hole a set screw cuts its own thread into. That depends on your printer and filament rather than on the pulley, so it is one setting for the whole app and both pulleys. It is saved with every design and download, so a design always re-exports with the holes it was made with.

Your default: new designs (and Reset) start from it. Tune the settings for your printer and press Save as my default. A design opened from a file or link keeps the values it was made with and doesn't change your default; the dialog then shows the design's values next to yours, with a use my default link.

  • Round with Thread engagement (default 50%) — 0% makes the hole the screw's outer diameter (no grip); 100% makes it the thread's root diameter (the screw cuts a full thread). Raise it if screws strip or spin; lower it if they're too hard to drive or crack the hub.
  • Hex with Hex flats (default 82%) — a hexagonal hole, across the flats as a percentage of the screw's diameter. The screw grips on the six flats and the corners give the displaced plastic somewhere to go, which suits brittle materials. A corner points up, so the hole prints without support.

D-flat (Bore Shape)

A D-profile shaft has one flat face milled along part of its length. Bore Shape D-flat (Size card) adds a matching flat chord cut in the bore so the pulley cannot rotate on the shaft.

  • Flat Depth (mm) — Distance from the bore wall inward to the flat face. Measure your actual shaft with calipers; a typical value for small motor shafts (5–8 mm) is 0.5 mm.
    The flat is oriented at 0° (+X direction in the cross-section). Rotate the pulley in your slicer to match a specific orientation.
  • With a set screw — pick it in Retention above: one radial screw aligned with the flat (at 0°), threaded, through a captured nut against the flat, or into a heat-set insert.

Keyway (Bore Shape)

A rectangular slot cut through the bore that accepts a standard parallel key (ISO 773 / DIN 6885-1). The key sits half in the shaft keyway and half in the hub keyway, transmitting torque through shear rather than friction.

  • Width W (mm) — Equal to key width b from ISO 773. Use Default Key to auto-fill the correct width for your bore diameter.
  • Hub Depth (mm) — Depth of the slot outward from the bore wall, corresponding to ISO 773 value t2 + corner clearance radius r.
    Do not use t2 alone — add r to allow the key to seat flush. The Default Key button applies t2 + r automatically.
  • Default Key Button — Looks up your bore in the ISO 773 table and fills in Width W and Hub Depth. Covers bore diameters 6–170 mm; if between entries, the next-larger standard size is used.
  • With a set screw — pick it in Retention above: one screw aligned with the keyway — threaded in to the slot, a captured nut against the slot's outer face, or a heat-set insert.
    A set screw over the keyway prevents axial movement even when the key alone would allow it.
  • Keyway Orientation — Always at 0° (+X direction). Rotate in your slicer or CAD tool to match a specific shaft clock position.
