⚙ Hub — 3D Guide

Enabling the Hub

Checkbox in the Hub section header. When checked, a cylindrical boss is built on top of the toothed section and included in the 3D preview and all exports (STL, STEP). When unchecked, no hub geometry is generated — the pulley is a plain toothed disk with a through-bore.

The Hub section is only visible in 3D Mode.

Hub OD (mm)

Outer diameter of the hub boss. Can be narrower or wider than the pulley OD — no restriction. A narrower hub tucks the boss inside the tooth rim; a wider hub creates a flange overhanging the teeth. For captured nut retention, the hub may grow a rounded lobe in the screw direction if the entered OD is too small to provide adequate wall thickness.

When the Spokes option is active, Hub OD is controlled by the pulley's 2D spokes setting.

Hub Height (mm)

Axial height of the hub boss above the toothed section. The bore runs through the full combined height (Belt Height + Hub Height). For captured nut retention, this value is automatically raised if the nut pocket requires more depth than entered — the 3D model uses the adjusted height without changing the input field.

Shaft Retention

  • None — No set screw or shaft feature is added. The bore is a plain through-hole. Suitable for a light-duty fit or when you will add your own retention (e.g. shaft collar, adhesive).
  • Set Screw (std.) — Radial screw hole(s) drilled from the outside of the hub in to the bore (one side only — the screw is tapped into the plastic or used with a heat-set insert). 1 screw = single perpendicular hole. 2 screws = holes placed 90° apart. Select screw size M3–M10.
  • Set Screw (captured nut) — A standard ISO hex nut is dropped into a pocket opening from the top face of the hub. The set screw threads through the hub OD into the nut and contacts the shaft. Stronger than threading into plastic.
    Select screw size M3–M10 first — nut pocket dimensions are calculated automatically from ISO 4032.
    ⓘ 3D Print Guide — captured nut assembly, pocket shape, print settings
  • D-Shaft — A flat chord is cut in the bore to match a D-profile motor shaft. See D-Shaft Retention below.
  • Keyway — A rectangular slot is cut through the bore to accept a standard parallel key (ISO 773 / DIN 6885). See Keyway Retention below.

Set Screw Size and Number of Screws

Set Screw Size sets the hole's diameter (M3 = 3 mm, … M10 = 10 mm); with a captured nut the nut pocket grows with it. Number of Screws: 1, or 2 — standard screws 90° apart, captured nuts 180° apart. Hovering Number of Screws shows the picture for the retention method you have selected.

D-Shaft Retention

A D-profile shaft has one flat face milled along part of its length. Selecting D-Shaft adds a matching flat chord cut in the bore so the pulley cannot rotate on the shaft.

  • Flat Depth (mm) — Distance from the bore wall inward to the flat face. Measure your actual shaft with calipers; a typical value for small motor shafts (5–8 mm) is 0.5 mm.
    The flat is oriented at 0° (+X direction in the cross-section). Rotate the pulley in your slicer to match a specific orientation.
  • Add Set Screw — Optionally adds a radial set screw hole aligned with the flat face (at 0°). Choose Standard for a hole from the outside of the hub in to the flat, or Captured nut for a top-pocket nut.

Keyway Retention

A rectangular slot cut through the bore that accepts a standard parallel key (ISO 773 / DIN 6885-1). The key sits half in the shaft keyway and half in the hub keyway, transmitting torque through shear rather than friction.

  • Width W (mm) — Equal to key width b from ISO 773. Use Default Key to auto-fill the correct width for your bore diameter.
  • Hub Depth (mm) — Depth of the slot outward from the bore wall, corresponding to ISO 773 value t2 + corner clearance radius r.
    Do not use t2 alone — add r to allow the key to seat flush. The Default Key button applies t2 + r automatically.
  • Default Key Button — Looks up your bore in the ISO 773 table and fills in Width W and Hub Depth. Covers bore diameters 6–170 mm; if between entries, the next-larger standard size is used.
  • Add Set Screw — Optionally adds a radial set screw hole aligned with the keyway. Standard = a hole from the outside in to the slot; Captured nut = top-opening pocket with the nut inner face against the keyway slot outer face.
    A set screw over the keyway prevents axial movement even when the key alone would allow it.
  • Keyway Orientation — Always at 0° (+X direction). Rotate in your slicer or CAD tool to match a specific shaft clock position.
