Hub Basics

Enabling the Hub
Checkbox in the Hub section header. When checked, a cylindrical boss is built on top of the toothed section and included in the 3D preview and all exports (STL, STEP). When unchecked, no hub geometry is generated — the pulley is a plain toothed disk with a through-bore.
The Hub section is only visible when 3D Features is active.
Hub OD (mm)
Outer diameter of the hub boss. Can be narrower or wider than the pulley OD — no restriction. A narrower hub tucks the boss inside the tooth rim; a wider hub creates a flange overhanging the teeth. For captured nut retention, the hub may grow a rounded lobe in the screw direction if the entered OD is too small to provide adequate wall thickness.
Hub Height (mm)
Axial height of the hub boss above the toothed section. The bore runs through the full combined height (Belt Height + Hub Height). For captured nut retention, this value is automatically raised if the nut pocket requires more depth than entered — the 3D model uses the adjusted height without changing the input field.

Shaft Retention

Retention — None
No set screw or shaft feature is added. The bore is a plain through-hole. Suitable for a light-duty fit or when you will add your own retention (e.g. shaft collar, adhesive).
Retention — Set Screw (std.)
Radial screw hole(s) drilled through the full hub diameter — the screw can be driven from either side with a hex key. 1 screw = single perpendicular hole. 2 screws = holes placed 90° apart for more secure grip. Select screw size M3–M10 to set the hole diameter.
Retention — Set Screw (captured nut)
A custom solution for 3D printed parts where a standard ISO hex nut replaces a tapped hole to hold the set screw. The nut is dropped into a pocket that opens from the top face of the hub and cannot rotate; the set screw threads through the hub OD into the nut and contacts the shaft. This is stronger than threading directly into plastic and survives many tighten/loosen cycles without stripping.
Select screw size M3–M10 first — the nut pocket dimensions are calculated automatically from ISO 4032.

Retention — D-Shaft
A flat chord is cut in the bore to match a D-profile motor shaft. See the D-Shaft Retention section below.
Retention — Keyway
A rectangular slot is cut through the bore to accept a standard parallel key (ISO 773 / DIN 6885). See the Keyway Retention section below.

D-Shaft Retention

A D-profile shaft has one flat face milled along part of its length. Selecting D-Shaft adds a matching flat chord cut in the bore so the pulley cannot rotate on the shaft. Torque is transmitted by the flat face rather than by shaft friction alone.
Flat Depth (mm)
Distance from the bore wall inward to the flat face — i.e. how much material is removed from the bore circle to create the flat. Measure your actual shaft with calipers; a typical value for small motor shafts (5–8 mm) is 0.5 mm.
The flat is oriented at 0° (the +X direction in the cross-section). If you need a specific orientation, rotate the pulley in your slicer.
Add Set Screw
Optionally adds a radial set screw hole aligned with the flat face (at 0°, perpendicular to the flat). Choose Standard for a through-hole across the hub diameter, or Captured nut for a top-pocket nut (same as the main hub captured nut option but fixed at one screw, one position).

Keyway Retention

A keyway is a rectangular slot cut through the bore that accepts a standard parallel key (ISO 773 / DIN 6885-1). The matching key sits half in the shaft keyway and half in the hub (pulley bore) keyway, transmitting torque through shear rather than friction. This is the standard retention method for moderate-to-high torque industrial drives.
Width W (mm)
Width of the keyway slot — equal to the key width b from ISO 773. The slot is centred in the bore at 0° (the +X direction) and extends symmetrically ±W/2 in the Y direction. Use the Default Key button to auto-fill the correct width for your bore diameter.
Hub Depth (mm)
Depth of the slot measured outward from the bore wall. This corresponds to ISO 773 value t2 (hub keyway depth) plus the corner clearance radius r. The added clearance ensures the key can fully seat without the key corners binding in the slot corners. Use Default Key to auto-fill the correct value.
Do not use t2 alone — add r to allow the key to seat flush. The Default Key button applies t2 + r automatically.
Default Key Button
Looks up your bore diameter in the ISO 773 standard table and fills in the recommended Width W and Hub Depth (t2 + r) for that bore size. The table covers bore diameters from 6 mm to 170 mm. If your bore falls between table entries the next-larger standard size is used.

Add Set Screw
Optionally adds a radial set screw hole aligned with the keyway (at 0°). Choose Standard for a through-hole across the hub diameter, or Captured nut for a top-opening hex nut pocket. When captured nut is selected, the nut pocket inner face is positioned against the outer (bottom) face of the keyway slot rather than the bore wall — this ensures the screw bears against the key, not into open space.
A set screw over the keyway prevents axial movement of the pulley along the shaft even when the key alone would allow it.
Keyway Orientation
The keyway slot is always cut at 0° — it projects in the +X direction from the bore centre. To match a shaft keyway at a specific clock position, rotate the pulley in your slicer or CAD tool after export.
