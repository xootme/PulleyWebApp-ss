⚎ Laser / Waterjet — Timing Pulleys

Layer Cake Method

The exported SVG or DXF profile can be imported into any CAD program (Fusion 360, FreeCAD, SolidWorks, etc.) and extruded to the thickness of your sheet material. Stack and bond multiple identical layers to build up the required belt width. This technique lets you produce accurate timing pulleys from flat sheet stock — acrylic, plywood, aluminium, or steel — using only a laser cutter or waterjet.

  1. Download the SVG or DXF profile from the 2D panel.
  2. Import into your CAD program and extrude to your sheet thickness (e.g. 3 mm or 6 mm).
  3. Cut the required number of layers and stack them concentrically.
  4. Bond layers with adhesive, press-fit a hub, or fasten with through-bolts.

Downloads for 2D Cutting

  • SVG — Download the pulley profile as SVG for import into laser cutter software (LightBurn, RDWorks, CorelDRAW, Inkscape). The profile is at 1:1 mm scale — no scaling required.
    Set Print Extra to 0 — laser and waterjet cuts are dimensionally accurate and need no compensation.
  • DXF — Download the pulley profile as DXF (R2010 format) for import into CAD/CAM software or waterjet controllers. Uses true arc entities — not polyline approximations.
