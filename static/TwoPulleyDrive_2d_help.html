Overview

Enable Two Pulley Drive to design a complete belt drive system with two pulleys. The tool calculates the required belt length, validates the centre distance, and keeps the gear ratio consistent as you adjust tooth counts.
Gear Ratio R = TeethP2 TeethP1
Belt Length L ≈ 2C + π2 (D1 + D2) + (D2 − D1)2 4C

Two Pulley Drive Toggle

Two Pulley Drive (checkbox)
When checked, the Pulley 2 panel appears and spacing/ratio controls become active. When unchecked, only Pulley 1 is shown.
Settings are saved automatically — toggling off and back on restores previous values.

Spacing Controls

Input Centre Distance (mm)
Distance between pulley centres. Primary layout dimension of the belt drive. Changing this automatically recalculates the required belt tooth count.
After typing, the centre distance snaps to the nearest value achievable by a whole-number belt tooth count.
If the distance is less than the minimum (shown in red), the pulleys would overlap — increase the distance or reduce pulley sizes.
Minimum Distance Note
Displayed in red when the centre distance is too small. Minimum ≈ (OD₁ + OD₂) / 2 + clearance.
Auto Belt Teeth
Number of teeth on the belt, calculated from centre distance and pulley diameters using the open belt length formula. Can also be typed — centre distance updates to match.
Standard belts are sold in fixed tooth counts. Use this field to match an off-the-shelf belt and read back the resulting centre distance.

Edit Priority — How the Three Values Interact

The drive has three linked values: Pulley 1 size, Gear Ratio, and Pulley 2 size. Behaviour depends on whether Lock Ratio is checked.
Lock Ratio ☑ (checked — default)
The current Gear Ratio is preserved when either pulley is edited. Editing P1 recalculates P2 to maintain the ratio. Editing P2 recalculates P1 to maintain the ratio. If a pulley would fall below its minimum tooth count, it is clamped at the minimum and the other pulley is recalculated from there.
Use Lock Ratio when you have a target ratio and want both pulleys to stay consistent as you explore sizes.
Lock Ratio ☐ (unchecked)
Each pulley is independent. Editing either pulley only updates the Gear Ratio display — the other pulley does not change.
Use when you have fixed pulley sizes and just want to know the resulting ratio.
Edit Gear Ratio (either mode)
P1 stays fixed; Pulley 2 is recalculated to the closest achievable ratio with whole-number teeth. Snaps to the exact achievable value after entry.

Ratio Controls

Auto Gear Ratio
Speed reduction/increase ratio. 1.0 = same speed on both pulleys. >1.0 = P2 slower (torque multiplication). <1.0 = P2 faster (speed increase).
Formula: R = TeethP2 / TeethP1
Editing keeps P1 fixed and drives P2. Snaps to the exact achievable ratio after entry.
▲/▼ Arrow Buttons
Steps Pulley 2 tooth count up or down by one tooth, then updates Gear Ratio. P1 always unchanged. Useful for fine-tuning when exact tooth counts matter.
Ratio Note (e.g. "20T : 30T")
Shows the actual tooth counts for P1 and P2. The Gear Ratio field rounds to three decimal places; tooth counts shown here are the ground truth.

Reset Button

Reset
Clears all saved settings from browser storage and reloads the page with factory defaults.
All customisations (both pulleys, centre distance, ratio) will be lost. This cannot be undone.

Workflow Tips

Designing for a known belt
Set centre distance first, note the Belt Teeth count, then adjust Belt Teeth to match the nearest standard belt length and read back the corrected centre distance.
Designing for a target ratio
Enable Lock Ratio, set Pulley 1 teeth, then type the desired ratio — Pulley 2 updates automatically. Fine-tune with the ▲/▼ buttons. Then set centre distance to match your available belt.
Downloading 2D
Each pulley panel has Download SVG and Download DXF buttons. For the complete belt drive drawing use the Download Belt button in the Pulley 1 panel.
