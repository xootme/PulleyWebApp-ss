⚙ Two Pulley Drive — 2D Guide

Overview

Enable Two Pulley Drive to design a complete belt drive system with two pulleys. The tool calculates the required belt length, validates the centre distance, and keeps the gear ratio consistent as you adjust tooth counts.

Two Pulley Drive Toggle

When checked, the Pulley 2 panel appears and spacing/ratio controls become active. When unchecked, only Pulley 1 is shown.

Settings are saved automatically — toggling off and back on restores previous values.

Spacing Controls

  • Input Centre Distance (mm) — Distance between pulley centres. Changing this automatically recalculates the required belt tooth count.
    After typing, the centre distance snaps to the nearest value achievable by a whole-number belt tooth count.
    If the distance is less than the minimum (shown in red), the pulleys would overlap — increase the distance or reduce pulley sizes.
  • Auto Belt Teeth — Number of teeth on the belt, calculated from the centre distance and pulley diameters. For metric belts, belt length = Belt Teeth × pitch (exact). For Imperial belts, the open belt formula is used. Can also be typed — centre distance and belt length update after a short pause.
    Standard belts are sold in fixed tooth counts. Use this field to match an off-the-shelf belt and read back the resulting centre distance and belt length.
  • Input Belt Length (mm) — Physical belt length (Belt Teeth × pitch). Can also be typed — snaps to the nearest whole tooth count after a short pause, then updates Belt Teeth and Centre Distance.
    Use this field when you know the belt length from a catalogue or measurement and want to find the matching tooth count and centre distance.
  • Grouped Controls Box — Centre Distance, Belt Teeth, and Belt Length are shown together inside an outlined box because they are three views of the same constraint — change any one and the other two update automatically.

Edit Priority — How the Three Values Interact

  • Lock Ratio ☑ (checked — default) — The current Gear Ratio is preserved when either pulley is edited. Editing P1 recalculates P2 to maintain the ratio; editing P2 recalculates P1.
    Use Lock Ratio when you have a target ratio and want both pulleys to stay consistent as you explore sizes.
  • Lock Ratio ☐ (unchecked) — Each pulley is independent. Editing either pulley only updates the Gear Ratio display.
    Use when you have fixed pulley sizes and just want to know the resulting ratio.
  • Edit Gear Ratio (either mode) — P1 stays fixed; Pulley 2 is recalculated to the closest achievable ratio with whole-number teeth.

Ratio Controls

  • Auto Gear Ratio — Speed reduction/increase ratio. 1.0 = same speed. >1.0 = P2 slower (torque multiplication). <1.0 = P2 faster (speed increase). Formula: R = TeethP2 / TeethP1
  • ▲/▼ Arrow Buttons — Steps Pulley 2 tooth count up or down by one tooth. P1 always unchanged. Useful for fine-tuning when exact tooth counts matter.
  • Ratio Note (e.g. "20T : 30T") — Shows the actual tooth counts for P1 and P2. The Gear Ratio field rounds to three decimal places; tooth counts here are the ground truth.

Reset Button

Clears all saved settings from browser storage and reloads the page with factory defaults.

All customisations (both pulleys, centre distance, ratio) will be lost. This cannot be undone.

Import Button

The 📂 Import button (toolbar, next to Reset) restores a previously exported design. Every SVG, DXF, and STEP file downloaded from this tool contains embedded design parameters. Selecting one of those files reads the parameters and repopulates all form fields — both pulleys, centre distance, hub, spokes, and flanges — exactly as they were when the file was exported.

Only files exported from this tool contain embedded parameters. Files from other CAD programs will show an error.

Workflow Tips

  • Designing for a known belt — Type the belt's physical length into Belt Length — it snaps to the nearest tooth count and fills in Belt Teeth and Centre Distance automatically. Alternatively, set Centre Distance first and adjust Belt Teeth to match the nearest standard size.
  • Designing for a target ratio — Enable Lock Ratio, set Pulley 1 teeth, then type the desired ratio — Pulley 2 updates automatically. Fine-tune with the ▲/▼ buttons. Then set centre distance to match your available belt.
  • Downloading 2D — Each pulley panel has Download SVG and Download DXF buttons. For the complete belt drive drawing use the Download Belt button in the Pulley 1 panel.
