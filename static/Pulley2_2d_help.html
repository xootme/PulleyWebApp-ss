Overview

Pulley 2 is the driven (output) pulley in a Two Pulley Drive system. It shares the belt profile (family and pitch) with Pulley 1 — only size, fit, and print settings can be adjusted independently. Its tooth count drives the gear ratio calculation.

Belt Lock

Locked Belt Label (e.g. "HTD 5M")
Shows the belt family and pitch inherited from Pulley 1. Pulley 2 always uses the same belt — a drive belt cannot change pitch mid-run.
To change the belt family or pitch, update those settings in the Pulley 1 panel.

Size

Input Number of Teeth
Pulley 2 has the lowest edit priority — editing it keeps Pulley 1 fixed and updates the Gear Ratio to reflect the new P2/P1 relationship. More teeth on P2 = lower output speed, higher output torque.
Auto Outer Diameter (mm)
Calculated from tooth count and pitch. Can be typed to reverse-calculate the nearest whole-number tooth count — useful for space constraints. The Gear Ratio updates to match, same as editing teeth directly.
Input Bore Diameter (mm)
Shaft hole for Pulley 2. Independent of Pulley 1 — the two pulleys can sit on different shaft sizes (e.g. motor shaft vs. output shaft). Minimum 1 mm.
For 3D-printed pulleys, add 0.2–0.4 mm over the nominal shaft diameter for FDM printing tolerance.
Read-only Pitch Diameter
Theoretical belt pitch-line diameter for Pulley 2. Used for belt length and centre distance calculations.
Formula: (Teeth × Pitch) / π

Advanced

Tooth Clearance
Controls extra room at the tip of each belt tooth in the Pulley 2 groove. Independent of Pulley 1. Tight = precision. Standard = recommended default. Loose = easier assembly. Custom = exact mm offset.
Matching the clearance preset across both pulleys keeps behaviour consistent along the belt run.
Backlash
Side-to-side play in Pulley 2 tooth grooves. Independent of Pulley 1. None / Tight / Standard / Loose / Custom — same meanings as Pulley 1.
3D Print Compensation (mm)
Uniform outward offset on Pulley 2 non-bore surfaces. Set independently if the two pulleys are printed in different orientations or on different printers. Typical range: 0.05–0.2 mm.
Set to 0 for laser-cut or machined parts.
