STD / S-series — alternate names

These profiles appear under several names depending on the manufacturer or region. All refer to the same ISO 13050 S-series large-radius arc-flank geometry: S-series (ISO official), STD (Super Torque Drive), S-HTD, and Synchroflex S (ContiTech trade name). If a belt datasheet lists an S-series pitch code (e.g. S8M), it is compatible with this family regardless of the trade name used.

RPP vs STD — not the same profile

ISO 13050 defines two distinct families: STD/S-series uses a large-radius circular arc flank (Rbb); RPP uses a parabolic curve (y' = K·x'²) with a tip fillet. Check your belt datasheet — if the pitch code starts with R (e.g. R8M), select RPP; if it starts with S (e.g. S8M), select STD / S-series.

Size

  • Input Number of Teeth — Determines pulley diameter directly. A minimum tooth count is enforced per belt specification to prevent undercutting.
  • Auto Outer Diameter (mm) — Calculated from tooth count and pitch. Can also be typed — the tool finds the nearest whole-number tooth count.
  • Input Bore Diameter (mm) — Central shaft hole diameter. Must be smaller than the pitch diameter. Minimum 1 mm.
    For 3D-printed pulleys, add 0.2–0.4 mm over the nominal shaft diameter to account for FDM printing tolerance.
  • Read-only Pitch Diameter — Theoretical belt pitch-line diameter used for belt length calculations. Formula: (Teeth × Pitch) / π

Download — 2D

  • SVG Drawing — Clean 2D SVG at 1:1 mm scale (teeth, bore, OD). Import into Fusion 360 (Insert → Insert SVG, scale 1 mm/unit), FreeCAD, Inkscape, or Illustrator. This is also what the 2D preview window shows.
  • SVG + Data — Same drawing plus a data panel listing all key dimensions. Useful for documentation and inspection records.
  • Download Pulley DXF — DXF of the pulley profile and bore using true arc entities. R2010 DXF format, dimensions in millimetres.
  • Download Belt (SVG or DXF) — In single-pulley mode: belt tooth cross-section only. In Two Pulley Drive mode: the complete two-pulley belt layout with separate BELT_BACK and BELT_TEETH layers.

Import Design

The 📂 Import button (toolbar, next to Reset) restores a previously exported design. Every SVG, DXF, and STEP file downloaded from this tool contains embedded design parameters. Clicking Import, then selecting one of those files, reads the parameters and repopulates all form fields exactly as they were when the file was exported.

Only files exported from this tool contain embedded parameters. Files from other CAD programs will show an error.
