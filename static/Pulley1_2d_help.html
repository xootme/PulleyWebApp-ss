STD / S-series — alternate names
These profiles appear under several names depending on the manufacturer or region. All refer to the same ISO 13050 S-series large-radius arc-flank geometry:
  • S-series — ISO 13050 official designation (S2M, S3M, S5M, S8M, S14M)
  • STD — Super Torque Drive, used by several European and Asian belt manufacturers
  • S-HTD — occasionally used to distinguish S-series from standard HTD curvilinear profiles
  • Synchroflex S — ContiTech / Continental trade name for their S-series belts
The "S" prefix in the pitch code (e.g. S8M) comes directly from the ISO S-series classification. If a belt datasheet lists an S-series pitch code, it is compatible with this profile family regardless of the trade name used.
RPP vs STD — not the same profile
Brecoflex and Breco use the name "RPP" (Rubber Positive Profile) for their belts, and some sources describe STD/S-series belts as "RPP S-series". However, ISO 13050 defines two distinct profile families:
  • STD / S-series — groove flanks defined by a large-radius circular arc (Rbb)
  • RPP — groove flanks defined by a parabolic curve (y' = K·x'²) with a tip fillet radius
Check your belt datasheet: if the pitch code starts with R (e.g. R8M), select RPP. If it starts with S (e.g. S8M), select STD / S-series.

Advanced

Tooth Clearance
Radial gap between the belt tooth tip and the groove bottom. Tight — groove depth reduced to contact the belt tooth tip. Std. — exactly per the applicable standard; correct for most applications. Loose — groove deepened 5% beyond Std.; easier belt seating, tolerates printed dimensional variation. Custom — enter any mm value (positive = deeper groove, negative = shallower).
Too little clearance makes the belt hard to seat and increases wear. Too much increases backlash.
Backlash
Tangential play between belt tooth and groove — how much the pulley can rotate before engaging when reversing. Tight — groove narrowed to match belt tooth root width; best for CNC or precision reversal. Std. — per the applicable standard; suitable for most drives. Loose — groove is widened by 5% of the belt's tooth width. Custom — enter any mm value; groove widens by half this value per side.
3D Print Compensation (mm)
Shrinks the groove profile inward to compensate for FDM dimensional bloat. Typical starting value: 0.1–0.2 mm. Set to 0 for CNC or resin printing.
