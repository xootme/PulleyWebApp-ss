Belt Profile

Family
Selects the belt standard family. Each family defines the tooth shape and pitch range. Common families include:
  • HTD — High Torque Drive; rounded tooth profile, widely used in robotics and 3D printers.
  • GT / GT2 / GT3 — Gates Tooth profile; improved accuracy over HTD, common in precision motion.
  • T-series (T2.5, T5, T10) — Trapezoidal profile; older standard, lower backlash at slow speeds.
  • MXL / XL / L / H — Imperial trapezoidal series; common in legacy and US-market equipment.
Changing the Family resets the Pitch options to only those available for that family.
Pitch
The center-to-center distance between adjacent belt teeth, in millimetres (e.g. 5M = 5 mm pitch). A larger pitch means a coarser, higher-torque belt; a smaller pitch gives finer resolution and quieter operation.
Pitch is locked to Family — choose your Family first, then select the Pitch.

Size

Number of Teeth Input
The number of teeth on the pulley. Determines the pulley diameter directly — more teeth = larger pulley. A minimum tooth count is enforced per belt spec to prevent undercutting.
Changing Teeth auto-updates Outer Diameter. Minimum value depends on the selected belt profile.
Outer Diameter (mm) Auto
The overall outside diameter of the pulley, calculated automatically from the tooth count and pitch. You can also type directly into this field — the tooth count will round to the nearest whole number and update accordingly.
Bore Diameter (mm) Input
The diameter of the central shaft hole. Set this to match your shaft. The bore must be smaller than the pitch diameter. Minimum bore is 1 mm.
For 3D-printed pulleys, add 0.2–0.4 mm to account for printing tolerance.
Pitch Diameter Read-only
The theoretical diameter at which the belt pitch line runs. Used internally for belt length calculations. Pitch diameter = (Teeth × Pitch) / π.

Advanced

Tooth Clearance
Controls how much extra room exists at the tip of each belt tooth inside the pulley groove.
  • Tight — Minimal clearance; best for precision drives, harder to assemble.
  • Standard — Recommended default; works well for most applications.
  • Loose — More clearance; easier assembly, slightly more noise.
  • Custom — Enter an exact offset in mm. Positive values increase groove depth.
Use Standard unless you are tuning for a specific fit or 3D print tolerance issue.
Backlash
Controls the side-to-side play between belt teeth and pulley grooves.
  • None — Zero extra gap; maximum positional accuracy, risk of binding if belt is not perfectly aligned.
  • Tight — Minimal play; suitable for precision servo drives.
  • Standard — Safe default for most applications.
  • Loose — More play; reduces binding risk at the cost of positioning accuracy.
  • Custom — Enter an exact tooth-width offset in mm.
3D Print Extra (mm)
Adds a uniform outward offset to all non-bore surfaces. Use this to compensate for filament over-extrusion or shrinkage on FDM printers. Typical range: 0.05 – 0.2 mm.
Set to 0 for laser-cut or machined parts. For FDM prints, start with 0.1 mm and iterate.

Download

Download Pulley SVG
Downloads a 2D SVG sketch of the pulley profile (teeth, bore, and outer diameter) ready to import into CAD tools such as Fusion 360, FreeCAD, Inkscape, or Illustrator. The geometry is drawn at a 1:1 mm scale.
In Fusion 360: Insert → Insert SVG → select the file → scale should be 1 mm/unit.
Download Belt
Downloads the belt in SVG or DXF format. SVG is best for CAD import. DXF exports the belt tooth cross-section profile in single-pulley mode, or the complete two-pulley belt layout with separate BELT_BACK and BELT_TEETH layers in Two Pulley Drive mode.
Download Pulley DXF
Downloads a DXF file of the pulley profile and bore using true arc entities. Output is in R2010 DXF format in millimetres, suitable for import into CAD applications that support DXF.
