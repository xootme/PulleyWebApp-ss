⚙ Spokes — 2D Guide

Enabling Spokes hollows out the pulley body between the outer rim ring and the hub boss, replacing solid material with evenly spaced radial spokes. The cutout profile appears in the 2D SVG and DXF exports and in the 3D preview.

Spoke Count

Number of equally spaced radial spokes. Range: 2–24. Even counts (4, 6, 8) are typical for symmetry. Higher counts on large pulleys fill more of the web area.

Hub OD (mm)

Outer diameter of the central hub boss that the spokes attach to at their inner end. This sets where the spoke root starts. Must be larger than the bore diameter.

When spokes are active, Hub OD in the 3D panel is locked to this value — the 3D hub boss matches the spoke hub OD automatically.

Rim Depth (mm)

Radial thickness of the solid outer rim ring, measured inward from the tooth OD. The rim ring is the structural band that carries the tooth loads; the spokes attach to its inner face.

Spoke Width (mm)

Tangential width of each spoke at its mid-span (halfway between hub boss and rim ring). The actual spoke narrows slightly toward the rim tip (where the fillet tip blends in) and widens at the hub base (fillet base).

Fillet Tip (mm)

Corner radius where the spoke meets the inner face of the rim ring. A larger fillet tip reduces stress concentration at the rim junction and improves fatigue life. Set to 0 for a sharp corner.

If adjacent fillet arcs overlap (spoke count is high and fillet tip is large), the fillet is automatically reduced to prevent geometry errors.

Fillet Base (mm)

Corner radius where the spoke meets the outer face of the hub boss. A larger fillet base is particularly important for load-bearing spokes — it distributes bending stress over a wider area.

Spoke Height (mm) (3D only)

Axial height of the spoke web. This controls how far the spokes extend through the pulley body in the axial direction.

  • 0 = full belt height (spokes span the entire axial thickness).
  • A positive value less than belt height creates a recessed pocket above and below the spoke web, leaving solid material on both faces. This is useful when you want a solid pulley face for mounting or gluing a flange.
Spoke Height is only visible when 3D Features is active. The 2D SVG/DXF profile always shows the full spoke cutout regardless of this setting.
⚠ Partial-height spokes (Spoke Height > 0) are temporarily unavailable for STEP export. Set Spoke Height to 0 (full-height) to generate a valid STEP file. DXF and STL exports are unaffected.

2D Export Behaviour

When spokes are enabled, the 2D SVG and DXF downloads include the spoke void cutout profiles. These can be used directly in laser or waterjet cutting software — the outer tooth profile, the bore, and the spoke voids are all separate closed paths on the same drawing.

Use Gen. Rim Layer to download the toothed rim ring as a separate 2D file — this is the outer portion of the pulley without the spoke web, suitable for layer-cake stacking methods.
