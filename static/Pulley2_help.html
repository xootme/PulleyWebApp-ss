⚙ Pulley 2 — Help Guide

Overview

Pulley 2 is the driven (output) pulley in a Two Pulley Drive system. It shares the belt profile (family and pitch) with Pulley 1 — only size, fit, and print settings can be adjusted independently. Its tooth count drives the gear ratio calculation.

Belt Lock Info

Belt Label (e.g. "HTD 5M") Locked
Shows the belt family and pitch currently selected in Pulley 1. Pulley 2 always uses the same belt profile — a drive belt cannot change pitch mid-run.
To change the belt family or pitch, update those settings in the Pulley 1 panel on the left.

Size

Number of Teeth Input
The number of teeth on Pulley 2. Pulley 2 has the lowest edit priority — editing it keeps Pulley 1 fixed and updates the Gear Ratio to reflect the new P2/P1 relationship. More teeth on P2 = lower output speed, higher output torque.
To drive P2 from a target ratio instead, type the ratio into the Gear Ratio field in the drive bar — that keeps the ratio fixed and recalculates P2. The ▲ / ▼ arrow buttons also step P2 by one tooth at a time.
Outer Diameter (mm) Auto
Calculated automatically from the tooth count and pitch. You can type a diameter here to reverse-calculate the nearest whole-number tooth count — useful when you have a space constraint. The Gear Ratio updates to match, just as if you had typed the tooth count directly.
Bore Diameter (mm) Input
The shaft hole diameter for Pulley 2. This is independent of Pulley 1 — the two pulleys can sit on different shaft sizes (e.g. motor shaft vs. output shaft). Minimum bore is 1 mm.
For 3D-printed pulleys, add 0.2–0.4 mm to account for FDM printing tolerance.
Pitch Diameter Read-only
The theoretical belt pitch-line diameter for Pulley 2. Used internally to calculate belt length and centre distance. Pitch diameter = (Teeth × Pitch) / π.

Advanced

Tooth Clearance
Controls how much extra room exists at the tip of each belt tooth inside the Pulley 2 groove. Independent of Pulley 1 — you can use different presets on each pulley if desired.
  • Tight — Minimal clearance; best for precision drives.
  • Standard — Recommended default.
  • Loose — Easier assembly, slightly more noise.
  • Custom — Enter an exact offset in mm.
In most drives, matching the clearance preset across both pulleys keeps behaviour consistent.
Backlash
Controls side-to-side play in the Pulley 2 tooth grooves. Independent of Pulley 1.
  • None — No extra gap; maximum positional accuracy.
  • Tight — Minimal play for precision servo drives.
  • Standard — Safe default.
  • Loose — Reduces binding risk.
  • Custom — Enter an exact offset in mm.
3D Print Compensation (mm)
Adds a uniform outward offset to Pulley 2's non-bore surfaces. Set independently from Pulley 1 if the two pulleys are printed in different orientations or on different printers. Typical range: 0.05 – 0.2 mm.
Set to 0 for laser-cut or machined parts.

Download

Download SVG
Downloads a 2D SVG sketch of Pulley 2 (teeth profile, bore, outer diameter) at 1:1 mm scale. Import into Fusion 360, FreeCAD, Inkscape, or any CAD tool that accepts SVG.
In Fusion 360: Insert → Insert SVG → scale should be 1 mm/unit. The sketch can then be extruded to create a solid body.
Download Pulley DXF
Downloads a DXF file of the Pulley 2 profile and bore using true arc entities. Output is in R2010 DXF format in millimetres, suitable for import into CAD applications that support DXF.
Belt Drive (SVG or DXF)
To download the complete two-pulley belt drive (both pulleys and belt path in one drawing), use the Download Belt (SVG or DXF) button in the Pulley 1 panel on the left. SVG is best for CAD import; DXF exports the full belt layout with separate BELT_BACK and BELT_TEETH layers.
Download Pulley STL
Downloads a binary STL file of the complete 3D solid for Pulley 2, including any hub boss and retention features. Geometry is exported in millimetres at the current Belt Height.
Pulley 1 and Pulley 2 each have their own STL download so you can slice and print them separately with different settings.
Download Pulley STEP
Downloads a STEP (AP214) file of Pulley 2 as a proper B-rep solid, including hub boss, bore, set-screw holes, and captured nut pockets. Import into Fusion 360, SolidWorks, FreeCAD, or any CAD tool that accepts STEP files.
Pulley 1 and Pulley 2 each have their own STEP download. STEP imports as an editable solid body, not a mesh.

3D — Hub

Enabling the Hub
The Hub section has a checkbox in its header. When checked, a cylindrical boss is built on top of Pulley 2's toothed section and included in the 3D preview and STL export. When unchecked the pulley is a plain toothed ring with a through bore.
Pulley 2's hub settings are completely independent of Pulley 1's. Each pulley can have a different hub OD, height, and retention method.
Hub OD (mm)
The outer diameter of the hub boss. May be smaller or larger than the pulley OD — no restriction. A hub narrower than the pulley tucks inside the tooth rim; a hub wider than the pulley creates a flange that overhangs the teeth.
Hub Height (mm)
Axial height of the hub boss above the toothed section (mm). The bore runs through the full combined height (Belt Height + Hub Height). For a captured nut, the height is auto-raised if the nut pocket requires more space than entered.
Retention Method — Set Screw (std.)
Drills one or two radial screw holes through the hub wall. The hole spans the full hub diameter so the set screw can be driven from either side with a hex key. Two screws are placed 90° apart. Choose the screw size (M3 – M10) to set the hole diameter.
Retention Method — Set Screw (captured nut)
A hex nut is captured in a top-opening pocket in the hub boss. The nut drops in from the hub top face and is located by two vertical flat faces; the screw enters from the hub OD, threads into the nut, and contacts the shaft. Two screws are placed 180° apart (directly opposite).
  • Hub height is auto-raised if too short for the nut pocket.
  • A rounded lobe is added to the hub in the screw direction if there is insufficient wall material outside the nut — ensuring at least two nut-thicknesses of material.
Select the screw size (M3 – M10); pocket dimensions are calculated automatically.
Captured nut retention is stronger than a plain set screw and survives multiple tighten/loosen cycles without stripping a printed hub.
Retention Method — D-Shaft
Adds a flat chord cut to the bore for a D-profile shaft. Enter the flat depth in mm — measure your actual shaft; a typical value is 0.5 mm.

3D — Preview

Viewing Pulley 2 in 3D
When Two Pulley Drive is enabled, click the 3D tab to open the interactive drive preview. Both pulleys and the belt are shown together, phase-aligned. To inspect Pulley 2 in isolation, use the Download STL to load the individual file in a slicer.
  • Orbit — Left-click and drag.
  • Zoom — Scroll wheel.
  • Pan — Right-click and drag.
