What is the Standalone Edition?

Each CheapCAD Tools standalone app is a self-contained Windows executable. It runs a local web server and opens in your default browser — so the interface looks identical to the online version, but everything happens on your machine. No internet connection required after activation.

Not a CAD plugin. Standalone tools do not integrate directly into CAD software. Files are exported (SVG, DXF, STEP, STL) and imported manually into your CAD program. For automatic import, see the CAD Plug-In Edition.
