Deployment Architecture

The application is hosted on Render.com using a containerized Python environment. Deployment is fully automated: any change pushed to the GitHub repository triggers an instant rebuild and redeploy on Render.

Infrastructure Note: We have moved away from GreenGeeks LiteSpeed/CGI to bypass severe permissions and execution limits. The app is now professional-grade and highly scalable.
2

One-Command Deployment

To push updates to the live website, simply commit and push your code to GitHub.

Terminal — Project Root
# 1. Stage your changes
git add .

# 2. Commit your work
git commit -m "Update pulley geometry for S-profiles"

# 3. Push to GitHub (Triggers Render Deploy)
git push origin main
Authentication: The local environment is linked to the Windows Credential Manager. You do not need to enter your GitHub token manually anymore.
