📂 Import Design

Every file exported from this tool — STEP, DXF, SVG, and STL — contains embedded design parameters. Selecting an exported file here will read those parameters and restore your design exactly as it was when exported.

⚠ Report A Bug
Test comments: This bug report tool is for testing purposes only. Reports are saved to a private log file and are not monitored regularly. For urgent issues please contact us directly.

What gets recorded when you submit:
  • The text you enter in the description fields above.
  • Your email address, if provided.
  • The current pulley settings (family, pitch, teeth, bore, hub, spoke, and flange values) so the issue can be reproduced.
  • The app version and build timestamp.
  • The page URL.
No account information, browser fingerprint, or IP address is stored. Reports are saved to a private log file and used only to improve the tool.
Cheap CAD Tools — Software Design Philosophy
Don't try to catch every setting that could make a part go wrong. Over-constraining the inputs leads to a poor user experience — for example, typing a number only to have the software reject it with a cryptic message. If you enter a value that produces a strange result, simply go back and try a smaller change.
